This repository is a program that writes one short text for make.fun's bounty `u-gudril-cool-one-line-best-line-b8c41f4d`: it writes the single line below as UTF-8 bytes, with no trailing newline, into the folder named by `MAKEFUN_OUTPUT_DIR` when that is set and `/output` otherwise, creating the folder, then prints the character count to stderr.


Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
